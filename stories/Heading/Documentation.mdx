# Heading

A Heading component that renders HTML headers from `H1` to `H6`  
Heading is UI/UX agnostic so you need to provide your style to have the look and feel you prefer.  
When you import the Heading component without providing any className or style associated will looks as following:

<Canvas of={HeadingStories.Unstyled} />

Note that the Heading label can be passed to the component:
- using the label prop
- as the child component within the Heading tags.

In this first example the content is passed as a label prop:

```js
<Heading
  level="h1"
  className="title"
  id="user-defined-id"
  props={{ role: 'heading' }}
  label="This is the content of the Heading"
/>
```

In this example instead the content is passed as a child component:

```js
<Heading
  level="h1"
  className="title"
  id="user-defined-id"
  props={{ role: 'heading' }}
>
  <div>
    <p>
      This is the content of the Heading
    </p>
  </div>
</Heading>
```
*Note:* the content (children) takes precedence of the label prop if both are provided.
