# Toggle

Toggle component ready to use in your UI  
Toggle is UI/UX agnostic so you need to provide your style to have the look and feel you prefer.
When you import the toggle component without providing any className or style associated will looks as following:

<Canvas of={ToggleStories.Unstyled} />

## Styling

The Toggle component does not include any built-in CSS within the dcx-react-library. To ensure the Toggle component is styled correctly, you need to import the relevant stylesheet. Here’s how you can include the necessary CSS in your project:

```js
/* The following line can be included in your src/index.js or App.js file */
import '@capgeminiuk/dcx-react-library/dist/dcx-react-library.css';
```

## Usage

Use the toggle component when users need to toggle a value

An example with all the available properties is:

```js
<Toggle
  checked={checked}
  onChange={(e) => {
    setChecked(e);
  }}
  onColor="orange"
  offColor="gray"
  disabled={true}
  borderRadius="0"
  customOnLabel={
    <FontAwesomeIcon
      icon={faCheck}
      style={{
        fontSize: '12px',
        display: 'flex',
        justifyContent: 'flex-start',
        marginLeft: '4px',
        alignItems: 'center',
        height: '100%',
        color: 'white',
      }}
    />
  }
  customOffLabel={
    <FontAwesomeIcon
      style={{
        fontSize: '12px',
        display: 'flex',
        justifyContent: 'flex-end',
        marginRight: '4px',
        alignItems: 'center',
        height: '100%',
        color: 'white',
      }}
      icon={faPowerOff}
    />
  }
/>
```
