# ToolTip

ToolTip component ready to use in your UI  
ToolTip is UI/UX agnostic so you need to provide your style to have the look and feel you prefer.  
A basic example of a tooltip is the following:

<Canvas of={ToolTiptories.Bottom} />

## Styling

The ToolTip component does not include any built-in CSS. To ensure the ToolTip component is styled correctly, you need to import the relevant stylesheet. Here’s how you can include the necessary CSS in your project:

```js
/* The following line can be included in your src/index.js or App.js file */
import '@capgeminiuk/dcx-react-library/dist/dcx-react-library.css';
```

## Usage

Use the ToolTip component when users need to show some infomration/tips.  
An example with all the available properties is:

```js
<ToolTip
  content={content}
  direction="bottom"
  className="tooltipClass"
  background="red"
  color="white"
>
  <b> Testing Bottom </b>
</ToolTip>
```
