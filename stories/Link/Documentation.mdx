# Link

A Link component ready to use in your form.  
Link is UI/UX agnostic so you need to provide your style to have the look and feel you prefer.  
When you import the Link component without providing any className or style associated will looks as following:

<Canvas of={LinkStories.Unstyled} />

In the first example the content is passed as a value Prop:

```js
<Link
  value="Google"
  to={link}
  className="myClass"
  props={{ target: '_blank' }}
/>
```

You can use the children feature but you should not use both, If you use both together, **value** take precedence.

```js
<Link
  to={link}
  className="myClass"
  props={{ target: '_blank' }}
>
  <p>Google</p>
</Link>
```
