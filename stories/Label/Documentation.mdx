# Label

A Label component ready to use in your form.  
Label is UI/UX agnostic so you need to provide your style to have the look and feel you prefer.  
When you import the label component without providing any className or style associated will looks as following:

<Canvas of={LabelStories.Unstyled} />

Note that the Label content can be passed to the component:
- using the value prop
- as the child component within the Label tags.

In the first example the content is passed as a value Prop:

```js
<Label
  className="additional classes"
  value="text"
  id="user-defined-id"
  props={{ style: { color: red } }}
/>
```

You can use the children feature but you should not use both, If you use both together, **value** take precedence.

```js
<Label
  className="additional classes"
  id="user-defined-id"
  props={{ style: { color: red } }}
>
  <p>text</p>
</Label>
```
