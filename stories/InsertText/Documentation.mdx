# InsertText

An InsertText component ready to use in your application.  
InsertText is UI/UX agnostic so you need to provide your style to have the look and feel you prefer.  
When you import the InsertText component without providing any className or associated style it will looks as following:

<Canvas of={InsertTextStories.Unstyled} />

Note that the InsertLink content can be passed to the component:
- using the value prop
- as the child component within the InsertLink tags.

In the first example the content is passed as a value Prop:

```js
<InsertText
  value="insert text"
  id="user-defined-id"
  className="my-class"
  props={{ style: { color: red } }}
/>
```
You can use the children feature but you should not use both, If you use both together, **value** take precedence.

```js
<InsertText
  value="insert text"
  id="user-defined-id"
  className="my-class"
  props={{ style: { color: red } }}
>
  <p>insert text</p>
</InsertLink>
```
