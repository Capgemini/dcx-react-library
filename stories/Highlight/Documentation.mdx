# Highlight

A Highlight component ready to use in your Typography.  
Highlight is UI/UX agnostic so you need to provide your style to have the look and feel you prefer.  
When you import the Highlight component without providing any className or style associated will looks as following:  

<Canvas of={HighlightStories.Unstyled} />

Note that the Highlight content can be passed to the component:
- using the value prop
- as the child component within the Highlight tags.

In the first example the content is passed as a value prop:

```js
<Highlight
  className="my-classname"
  value="This is the content of the highlighted text."
  props={{ id: 'my-highlight' }}/>
```

You can use the child feature but you should not use both, If you use both together, **value** take precedence.

```js
<Highlight
  className="my-classname"
  props={{ id: 'my-highlight' }}>
  This is the content of the highlighted text.
</Highlight>  
```
