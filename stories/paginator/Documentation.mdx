# Paginator

Paginator is a UI/UX agnostic component so you need to provide your style to create the look and feel that you need.  
Use the Paginator component to efficiently navigate through content spread across multiple pages, ensuring users can easily access relevant information without overwhelming them with too much data at once.  
When you import the Paginator component without providing any className or style associated will looks as following:

<Canvas of={PaginatorStories.Unstyled} />

An example with all the available properties is:

```jsx
<Paginator
  paginatorClassName=""
  currentPage={5}
  currentPageClassName=""
  totalPages={15}
  previousButton={<>Prev</>}
  previousButtonClassName=""
  nextButton={<>Next</>}
  nextButtonClassName=""
  pageNumbersClassName=""
  sibilingCount= {3}
  boundaryCount {2}
/>
```
