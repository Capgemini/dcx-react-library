# CodeSnippet

A CodeSnippet component ready to use in your Typography.  
CodeSnippet is UI/UX agnostic so you need to provide your style to have the look and feel you prefer.  
When you import the CodeSnippet component without providing any className or style associated will looks as following:  

<Canvas of={CodeSnippetStories.Unstyled} />

Note that the CodeSnippet content can be passed to the component:
- using the value prop
- as the child component within the CodeSnippet tags.

In the first example the content is passed as a value prop:

```js
<CodeSnippet
  value="This is the content of the CodeSnippet."
  className="my-classname"
  props={{ id: 'my-code' }}
/>
```

You can use the children feature but you should not use both, If you use both together, **value** take precedence.

```js
<CodeSnippet
  className="my-classname"
  props={{ id: 'my-code' }}
>
  <p>This is the content of the CodeSnippet.</p>
</CodeSnippet>
```
