# KeyboardInput

KeyboardInput component ready to use in your application.  
KeyboardInput is UI/UX agnostic so you need to provide your style to have the look and feel you prefer.  
When you import the KeyboardInput component without providing any className or associated style it will looks as following:

<Canvas of={KeyboardInputStories.Unstyled} />

Note that the KeyboardInput content can be passed to the component:
- using the value prop
- as the child component within the KeyboardInput tags.

In the first example the content is passed as a value prop:

```js
<KeyboardInput
  className="additional classes"
  value="ctrl+p"
  id="user-defined-id"
  props={{ style: { color: red } }}
/>
```

You can use the children feature but you should not use both, If you use both together, **value** take precedence.

```js
<KeyboardInput
  className="additional classes"
  id="user-defined-id"
  props={{ style: { color: red } }}
>
  <p>ctrl+p</p>
</KeyboardInput>
```
