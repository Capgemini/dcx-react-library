# Abbreviate

A abbreviate component ready to use in your Typography.  
Abbreviate is UI/UX agnostic so you need to provide your style to have the look and feel you prefer.  
When you import the abbreviate component without providing any className or style associated will looks as following:  

<Canvas of={AbbreviateStories.Unstyled} />

Note that the Abbreviate content can be passed to the component:
- using the value prop
- as the child component within the Abbreviate tags.

In the first example the content is passed as a value prop:

```js
<Abbreviate
  title="Laugh Out Loud"
  value="LOL"
  className="my-classname"
/>
```

You can use the children feature but you should not use both, If you use both together, **value** take precedence.

```js
<Abbreviate
  title="Laugh Out Loud"
  className="my-classname"
>
  <div>
    <p>LOL</p>
  </div>
</Abbreviate>
```
